## Kibana 8.19.18

The 8.19.18 release includes the following fixes.

### Fixes

Alerting and cases::
* Fixes case pushes only stamping a subset of attachments, which caused the alert count comment to be duplicated in the external system on every push ({kibana-pull}274451[#274451]).
Dashboards and Visualizations::
* Fixes **Canvas** autoplay not advancing past the first page ({kibana-pull}272619[#272619]).
Data ingestion and Fleet::
* Improves `POST /api/fleet/setup` performance for deployments with a large number of configured outputs by no longer decrypting every output on each call ({kibana-pull}273848[#273848]).
* Fixes a crash in the **Integrations** view when a package has no icon ({kibana-pull}273191[#273191]).
Developer tools::
* Fixes **Dev Tools Console** autocomplete in query filter context to suggest query DSL instead of the obsolete Elasticsearch 1.x filter DSL ({kibana-pull}272907[#272907]).
Elastic Observability solution::
* Fixes deleting a label from a Synthetics monitor not persisting on edit ({kibana-pull}274404[#274404]).
Elastic Security solution::
For the Elastic Security 8.19.18 release information, refer to {security-guide}/release-notes.html[_Elastic Security release notes_].
Kibana platform::
* Fixes the Files plugin blob download to return the requested file type ({kibana-pull}274783[#274783]).
* Fixes an issue where the Kibana JSON logger could produce JSON objects with a large number of numbered keys ({kibana-pull}256233[#256233]).


## Kibana 8.19.17

The 8.19.17 release includes the following known issues and fixes.

### Known issues

**Canvas Autoplay stops advancing after one page.**
*Details* +
Multipage Canvas visualizations stop advancing after one page when in autoplay mode

*Workaround* +

*Resolved* + 
This issue is resolved in 8.19.18 and 9.3.7.

### Fixes

Alerting::

Data ingestion and Fleet::
* Fixes data stream selectors in input packages with multiple policy templates incorrectly sharing or duplicating variables between templates ({kibana-pull}273364[#273364]).
* Improves response time of the agent policies list by computing counts in a single aggregation instead of multiple queries per policy ({kibana-pull}272429[#272429]).
* Fixes missing security rule names in the **Integrations → Assets** tab ({kibana-pull}272089[#272089]).

Elastic Observability solution::

* Fixes status tiles in the SLO Overview so that newly created SLOs are counted consistently with the per-row **No Data** badge ({kibana-pull}266315[#266315]).
