## Kibana 8.19.24

The 8.19.24 release includes the following enhancements and fixes.

**Important:** The 8.19.24 release contains fixes for potential security vulnerabilities. Check our [security advisory](https://discuss.elastic.co/c/announcements/security-announcements/31) for more details.

### Enhancements

Elasticsearch solution::
* Clarify in the Salesforce connector's document-level security tooltip that access applies per object type, not per record ({kibana-pull}297728[#297728]).

### Fixes

Alerting::
* Fix rules creating duplicate alerts, and leaving the original alerts active, when a rule run stops before it saves its state ({kibana-pull}293521[#293521]).
* Fix rules and background tasks silently stopping for several minutes when a concurrent update prevents their completed run from being recorded ({kibana-pull}295415[#295415]).
Dashboards and Visualizations::
* Fix Lens metric panels failing to render when filters return no results and dynamic coloring uses a maximum dimension ({kibana-pull}297429[#297429]).
Data ingestion and Fleet::
* Fix deleting an agent policy silently leaving its ID in shared integration policies. The delete now fails with an error that explains the cause ({kibana-pull}300189[#300189]).
* Fix Fleet running Elasticsearch transforms from uploaded integration packages with Kibana's internal system identity. Transforms in uploaded packages now run as the user who installed the package ({kibana-pull}297771[#297771]).
Data management::
* Fix the runtime field editor discarding the script when you change the field type to or from `composite` ({kibana-pull}299025[#299025]).
* Fix the runtime field preview not showing a field's custom label, and the preview row disappearing while documents load ({kibana-pull}299810[#299810]).
* Fix saved object labels showing "index patterns" instead of "data views" when you copy a dashboard that references data views in another space ({kibana-pull}297621[#297621]).
Discover::
* Fix field type icons staying stale in the field list when you recreate an index with a different mapping type for an existing field ({kibana-pull}301198[#301198]).
* Fix the **Url** field formatter adding an extra `/app` segment to relative URLs that start with a slash when Kibana runs behind a base path or in a custom space ({kibana-pull}299116[#299116]).
Elastic Security solution::
For the Elastic Security 8.19.24 release information, refer to {security-guide}/release-notes.html[_Elastic Security release notes_].
Elasticsearch solution::
* Fix content connector indexes created from Kibana failing to ingest documents with large numeric IDs by mapping the document `id` field as `keyword` ({kibana-pull}297711[#297711]).
* Fix the **Rule ID**, **Metadata field**, and **Values** tooltips on the query rules **Create rule** page not being announced by screen readers in Chrome with VoiceOver ({kibana-pull}295021[#295021]).
Kibana platform::
* Fix tag filters in listing pages, such as the dashboards list, returning no results when a tag name contains an ampersand (`&`) ({kibana-pull}297231[#297231]).
* Fix Permissions-Policy violation reports reaching the configured reporting endpoint only for the last directive. Reports for every directive now reach it ({kibana-pull}299786[#299786]).
* Fix the Analytics overview page showing the **Ingest your data** section when you can't add data or upload files ({kibana-pull}297717[#297717]).
* Fix paging through the API keys list showing the same API key on more than one page, or leaving a key out ({kibana-pull}296117[#296117]).
Machine Learning::
* Fix the data frame analytics audit messages API returning messages for jobs that don't exist in the current Kibana space ({kibana-pull}297821[#297821]).
* Fix the ES|QL field statistics table being left empty when you change the query or time range while statistics are still loading ({kibana-pull}298642[#298642]).
* Fix streaming inference connector requests returning no content when `elasticsearch.compression` is enabled ({kibana-pull}290381[#290381]).

## Kibana 8.19.21

The 8.19.21 release includes the following breaking changes and fixes.

**Important:**
The 8.19.21 release contains fixes for potential security vulnerabilities.
For details, go to the [security announcements](https://discuss.elastic.co/c/announcements/security-announcements/31).

### Breaking changes

The email connector now verifies TLS certificates on HTTPS proxies by default. Connections to hosts with self-signed, expired, or hostname-mismatched certificates that previously succeeded will now fail. 

To keep the previous behavior on the proxy connection, set `xpack.actions.ssl.proxyVerificationMode` to `none`. 

Per-host `xpack.actions.customHostSettings` (custom CA or relaxed hostname) does not apply to the proxy connection. Only self-managed deployments that route email through an HTTPS proxy are affected ({kibana-pull}283150[#283150]).

### Fixes

Alerting::
* Fix alert suppression for alerts stored with nested `_source` fields to prevent creating duplicate alerts instead of updating existing ones ({kibana-pull}282192[#282192]).

Developer tools::

* Fix Console autocomplete inserting boolean and numeric values as quoted strings instead of JSON primitives ({kibana-pull}286699[#286699]).
* Fix Console body autocomplete failing after closed triple-quoted string values ({kibana-pull}286695[#286695]).
* Fix Console autocomplete not triggering at request body positions, and correct template expansion and text corruption bugs when accepting suggestions ({kibana-pull}284530[#284530]).
* Fix Console incorrectly showing autocomplete suggestions inside non-query triple-quoted strings ({kibana-pull}282424[#282424]).
Elastic Observability solution::

* Fix custom threshold rate aggregation to correctly alert when a counter increases from 0 ({kibana-pull}283973[#283973]).
