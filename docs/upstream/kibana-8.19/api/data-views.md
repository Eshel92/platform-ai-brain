## Data views API

Manage data views, formerly known as Kibana index patterns.

For the latest details, refer to [data view APIs](https://www.elastic.co/docs/api/doc/kibana/group/endpoint-data-views).

**Warning:** Do not write documents directly to the `.kibana` index. When you write directly
to the `.kibana` index, the data becomes corrupted and permanently breaks future Kibana versions.
