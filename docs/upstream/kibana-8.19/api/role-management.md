## Kibana role management APIs

Manage the roles that grant Kibana privileges.

**Warning:** Do not use the [Elasticsearch role management APIs](https://www.elastic.co/guide/en/elasticsearch/reference/8.19/security-api.html#security-role-apis) to manage Kibana roles.

For the latest API details, refer to [role APIs](https://www.elastic.co/docs/api/doc/kibana/group/endpoint-roles).
