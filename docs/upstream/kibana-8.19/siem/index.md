# Elastic Security overview

Elastic Security combines threat detection analytics, cloud native security, and endpoint protection capabilities in a single solution, so you can quickly detect, investigate, and respond to threats and vulnerabilities across your environment. To learn more about how Elastic Security works and what it offers, refer to the {security-guide}/es-overview.html[documentation].
