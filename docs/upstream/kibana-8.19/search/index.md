# Search

The *Search* space in the Kibana UI contains the following GUI features:

* [Connectors](https://www.elastic.co/guide/en/enterprise-search/current/connectors.html)
* [Web crawler](https://www.elastic.co/guide/en/enterprise-search/current/crawler.html)
* Playground
* [Search Applications](https://www.elastic.co/guide/en/elasticsearch/reference/current/search-application-overview.html)
* [Behavioral Analytics](https://www.elastic.co/guide/en/elasticsearch/reference/current/behavioral-analytics-overview.html)
* Inference Endpoints UI
* AI Assistant for Search
* Dev Tools Console
