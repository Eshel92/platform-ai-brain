## Debug Painless scripts

beta::[]

The *Painless Lab* is an interactive code editor that lets you test and
debug [Painless scripts](https://www.elastic.co/guide/en/elasticsearch/reference/8.19/modules-scripting-painless.html) in real-time.
You can use the Painless scripting
language to create Kibana runtime fields,
process [reindexed data](https://www.elastic.co/guide/en/elasticsearch/reference/8.19/docs-reindex.html), define complex
Watcher conditions,
and work with data in other contexts.

Find *Painless Lab* by navigating to the *Developer tools* page using the
navigation menu or the global search field.
