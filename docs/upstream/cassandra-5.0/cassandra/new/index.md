# New Features

## New Features in Apache Cassandra 5.0

This section covers the new features in Apache Cassandra 5.0.

* Storage Attached Indexes: Docs, [CEP-7](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-7%3AStorageAttached+Index),  [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-16052)
* Trie memtables: [CEP-19](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-19%3ATriememtable+implementation), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-17240)
* Trie SSTables: [CEP-25](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-25%3ATrie-indexedSSTable+format), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18398)
* JDK 17: Docs, [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-16895)
* More guardrails: [NEWS.txt](https://github.com/apache/cassandra/blob/trunk/NEWS.txt)
* TTL and writetime on collections and UDTs: Docs, [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-8877)
* New vector data type: Docs, [CEP-30](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-30%3AApproximateNearestNeighbor%28ANN%29VectorSearchviaStorage-AttachedIndexes), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18504)
* New vector similarity functions: Docs, [CEP-30](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-30%3AApproximateNearestNeighbor%28ANN%29VectorSearchviaStorage-AttachedIndexes), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18640)
* Unified Compaction Strategy: Docs, [CEP-26](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-26%3AUnifiedCompaction+Strategy), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18397)
* New Mathematical CQL functions: abs, exp, log, log10 and round: Docs, [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-17221)
* Dynamic Data Masking: Docs, [CEP-20](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-20%3ADynamicData+Masking), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-17940)
* New CIDR authorizer: [CEP-33](https://cwiki.apache.org/confluence/display/CASSANDRA/CEP-33%3ACIDRfiltering+authorizer), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18592)
* Extend maximum expiration date (TTL): [NEWS.txt](https://github.com/apache/cassandra/blob/trunk/NEWS.txt), [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-14227)
* New CQL native scalar functions for collections: [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18060)
* New sstablepartitions offline tool to find large partitions: [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-8720)
* New snitch for Microsoft Azure: [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18646)
* Pluggable crypto provider: [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-18624)
* New virtual table to view system logs: [JIRA ticket](https://issues.apache.org/jira/browse/CASSANDRA-17948)
