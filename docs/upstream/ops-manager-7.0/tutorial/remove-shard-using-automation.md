# Remove a Shard from a MongoDB Cluster

**New in version:** 7.0

You can use Ops Manager to remove a shard from a MongoDB sharded cluster. 

**Step 1: Navigate to the Clusters view for your deployment.**

a. If it is not already displayed, select the organization that
   contains your desired project from the `office` Organizations menu in the
   navigation bar.

#. If it is not already displayed, select your desired project
   from the Projects menu in the navigation bar.

#. If it is not already displayed, click Deployment in 
   the sidebar.

#. Click the Clusters view.

**Step 2: Click Modify on the cluster where you want to remove a shard.**

**Step 3: In the Member Configuration section, remove a shard.**

a. Expand SHARD SETTINGS.

b. Click the `ellipsis` next to the shard you want to remove.
c. Click Remove from Cluster.
