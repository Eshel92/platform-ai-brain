# View a Backup's Snapshots

## Overview

By default, Ops Manager takes a base snapshot of a backed-up deployment every 6
hours and retains snapshots as described in
snapshot-frequency-and-retention. Administrators can change the
frequency and retention settings.

You can view all available snapshots, as described here.

## Procedure

**Step 1: Click Continuous Backup, then the Overview tab.**

**Step 2: On the line listing the process, click the ellipsis icon and click View All Snapshots.**
