# Change Snapshot Expiration

## Overview

Ops Manager retains snapshots for the number of days specified in the
`Base Retention of Snapshots (in Days)` setting. This procedure changes
how long Ops Manager retains *one specific snapshot*.

## Procedure

**Step 1: Click Continuous Backup, then the Overview tab.**

**Step 2: Select the snapshot to edit.**

a. On the line listing the snapshot, click the ellipsis [...] icon.
b. Click Edit Expiration Date.

**Step 3: Choose the Expiration Date and Time for the selected snapshot.**

If you want to set a specific expiration date and time:

a. Click the Expiration Date field. Choose a date from the
   calendar.

b. Click the Expiration Time field. Choose a time from the
   clock.

If you want the snapshot to never expire, click Does Not Expire.

**Step 4: Click Save.**
