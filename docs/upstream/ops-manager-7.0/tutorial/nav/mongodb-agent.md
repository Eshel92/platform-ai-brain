# MongoDB Agent

Before the introduction of the MongoDB Agent, each function --
Automation, Backup, and Monitoring -- ran as a separate agent binary in
your project.

The MongoDB Agent runs as a single binary that can perform any -- or all
-- of the three functions depending upon what you need.

- Activate the monitoring and/or backup functions using Ops Manager UI.
- Activate automation when you create a new cluster or import an
  existing one.
