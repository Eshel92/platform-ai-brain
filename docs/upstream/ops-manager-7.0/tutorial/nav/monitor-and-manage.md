# Manage Deployments

You can manage MongoDB Atlas clusters both manually and programatically 
with a variety of tools, such as the Atlas UI, the Atlas CLI, Ops Manager 
and more. 

Managing MongoDB clusters involves tasks such as editing a cluster configuration, 
upgrading an existing cluster, migrating to a new version of MongoDB and more.
