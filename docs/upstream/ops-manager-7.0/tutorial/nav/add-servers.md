# Provision Servers

Ops Manager can automate operations for your MongoDB processes. Ops Manager can manage existing processes and schedule new processes.

Ops Manager polls the MongoDB Agent, 
which you must install on every MongoDB server to maintain alignment 
between your desired state and the actual state of your MongoDB server.
