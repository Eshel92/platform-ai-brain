# Administration Console

If you have the `Global Owner` role for your Ops Manager
deployment, click the Admin link in the top right corner of
the Ops Manager Application to access the administration console.

**See also:**

- To learn how to configure Ops Manager, see
  /reference/config/ui-settings.

- To learn about the Ops Manager configuration settings, see
  /reference/configuration.
