# Ops Manager Migration Licensing

This /reference/legal/live-migration-atlas-license
covers MongoDB Community customers who wish to use the Live Migration
feature, available in Ops Manager 5.0 and later, to migrate MongoDB to Atlas.

The use of the Ops Manager software with this license agreement is restricted
to the use of the Live Migration feature only.
