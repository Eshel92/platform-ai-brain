# Version Manifest

The `versionManifest` resource provides the ability to view or
retrieve the Version Manifest.

**See also:**

om-update-version-manifest-api-tutorial

   
Base URL: `https://{OPSMANAGER-HOST}:{PORT}/api/public/v1.0`

## Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | /unauth/versionManifest | Retrieve the Version Manifest that Ops Manager is configured to use. |
| `PUT` | /versionManifest | Update the Version Manifest. |
