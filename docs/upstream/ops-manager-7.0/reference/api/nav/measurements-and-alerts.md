# Measurements and Alerts

**Note:**

Groups and projects are synonymous terms. Your `{PROJECT-ID}` is the
same as your project id. For existing groups, your group/project id
remains the same. This page uses the more familiar term group when
referring to descriptions. The endpoint remains as stated in the
document.

The Ops Manager API exposes the following
measurement and alert resources:

- /reference/api/measurements
- /reference/api/alerts
- /reference/api/alert-configurations
- /reference/api/events
- /reference/api/global-alerts
- /reference/api/global-alert-configurations
- /reference/api/global-events
- /reference/api/maintenance-windows
- /reference/api/performance-advisor
- /reference/api/third-party-integration-settings
