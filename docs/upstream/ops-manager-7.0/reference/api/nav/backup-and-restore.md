# Backup and Restore

**Note:**

Groups and projects are synonymous terms. Your `{PROJECT-ID}` is the
same as your project id. For existing groups, your group/project id
remains the same. This page uses the more familiar term group when
referring to descriptions. The endpoint remains as stated in the
document.

The Ops Manager API exposes the following
backup and restore resources:

- /reference/api/backup-configurations
- /reference/api/snapshot-schedule
- /reference/api/snapshots
- /reference/api/checkpoints
- /reference/api/restore-jobs
