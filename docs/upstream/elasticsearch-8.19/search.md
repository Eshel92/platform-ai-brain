## Search APIs

**New API reference**
For the most up-to-date API details, refer to [Search APIs](https://www.elastic.co/docs/api/doc/elasticsearch/group/endpoint-search).

Search APIs are used to search and aggregate data stored in Elasticsearch indices and
data streams. For an overview and related tutorials, see search-your-data.

Most search APIs support multi-target syntax, with the
exception of the explain API.
