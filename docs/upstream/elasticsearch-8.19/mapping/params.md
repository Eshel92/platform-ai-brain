## Mapping parameters

The following pages provide detailed explanations of the various mapping
parameters that are used by field mappings:

The following mapping parameters are common to some or all field data types:

* `coerce`
* `copy_to`
* `doc_values`
* `dynamic`
* `eager_global_ordinals`
* `enabled`
* `fielddata`

* `format`

* `index_options`
* `index_phrases`
* `index_prefixes`
* `index`
* `meta`
* `normalizer`

* `null_value`
* `position_increment_gap`
* `properties`
* `search_analyzer`
* `similarity`
