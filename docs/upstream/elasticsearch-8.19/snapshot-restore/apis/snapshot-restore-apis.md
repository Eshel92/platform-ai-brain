## Snapshot and restore APIs

**New API reference**
For the most up-to-date API details, refer to [Snapshot and restore APIs](https://www.elastic.co/docs/api/doc/elasticsearch/group/endpoint-snapshot).

You can use the following APIs to set up snapshot repositories, manage snapshot
backups, and restore snapshots to a running cluster.

For more information, see snapshot-restore.

### Snapshot repository management APIs

* Create or update snapshot repository
* Verify snapshot repository
* Get snapshot repository
* Delete snapshot repository
* Clean up snapshot repository

### Snapshot management APIs

* Create snapshot
* Clone snapshot
* Get snapshot
* Get snapshot status
* Restore snapshot
* Delete snapshot
