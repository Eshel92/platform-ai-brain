## Fleet APIs

**New API reference**
For the most up-to-date API details, refer to [Fleet APIs](https://www.elastic.co/docs/api/doc/elasticsearch/group/endpoint-fleet).

**Tip:** For the Kibana Fleet APIs, see the
{fleet-guide}/fleet-api-docs.html[Fleet API Documentation].

The following APIs support Fleet's use of Elasticsearch as a data store for internal
agent and action data. These APIs are experimental and for internal use by
Fleet only.

* Get global checkpoints
* Fleet search
* Fleet multi search
