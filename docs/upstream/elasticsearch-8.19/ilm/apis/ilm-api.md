## Index lifecycle management APIs

**New API reference**
For the most up-to-date API details, refer to [Index lifecycle management APIs](https://www.elastic.co/docs/api/doc/elasticsearch/group/endpoint-ilm).

You use the following APIs to set up policies to automatically manage the index lifecycle.
For more information about index lifecycle management (ILM), see index-lifecycle-management.

### Policy management APIs

* Create lifecycle policy
* Get lifecycle policy
* Delete lifecycle policy

### Index management APIs

* Move index to step
* Retry policy on indices
* Remove policy from index

### Operation management APIs

* Get ILM operation mode
* Start ILM
* Stop ILM
* Explain API
* Migrate to data tiers routing API
