# API quick reference

All transform endpoints have the following base:

```js
_transform/
```

* Create transforms
* Delete transforms
* Get transforms
* Get transforms statistics
* Preview transforms
* Reset transforms
* Schedule now transforms
* Start transforms
* Stop transforms
* Update transforms

For the full list, see transform-apis.
