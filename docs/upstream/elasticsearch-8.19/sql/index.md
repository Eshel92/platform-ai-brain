# SQL

Elasticsearch includes a SQL feature to execute SQL queries against indices and return results in tabular format.

The following chapters aim to cover everything from usage, to syntax and drivers.
Experienced users or those in a hurry might want to jump directly to
the list of SQL commands and functions.
