## Elasticsearch version 8.19.24

Also see Breaking changes in 8.19.

**Important:**
This release contains security fixes.
Please see our [security advisory](https://discuss.elastic.co/c/announcements/security-announcements/31) for more details.

### Known issues

* When resuming an incomplete downsampling operation, Elasticsearch uses a checkpoint to avoid rescanning the entire shard. In certain edge cases, Elasticsearch may incorrectly identify this checkpoint and skip source data, resulting in an incomplete downsampled index. Fixed by [#164646](https://github.com/elastic/elasticsearch/pull/164646).
