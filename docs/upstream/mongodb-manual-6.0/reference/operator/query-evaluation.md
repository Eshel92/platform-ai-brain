# Evaluation Query Operators

Evaluation operators return data based on evaluations of either 
individual fields or the entire collection's documents.  

**Note:**

For details on a specific operator, including syntax and examples,
click on the link to the operator's reference page.

| Name | Description |
|---|---|
| `$expr` | Allows use of aggregation expressions within the query language. |
| `$jsonSchema` | Validate documents against the given JSON Schema. |
| `$mod` | Performs a modulo operation on the value of a field and selects documents with a specified result. |
| `$regex` | Selects documents where values match a specified regular expression. |
| `$where` | Matches documents that satisfy a JavaScript expression. |
