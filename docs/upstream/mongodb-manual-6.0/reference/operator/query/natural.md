# $natural

## Definition

**`$natural`**

Use in conjunction with `cursor.hint()` to perform a
collection scan to return documents in natural order.

For usage, see hint-collection-scans example in the
`cursor.hint()` reference page.

You can specify a `$natural` sort when running a `find` 
operation against a view.
