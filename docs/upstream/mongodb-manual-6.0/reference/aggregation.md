# Aggregation Reference

You can run aggregation pipelines in the UI for deployments hosted in [MongoDB Atlas](https://www.mongodb.com/docs/atlas?tck=docs_server).

## Aggregation Resources

agg-pipeline-quick-ref
   Quick reference card for aggregation pipeline.

/reference/operator/aggregation/interface
   The reference for the data aggregation commands, which provide the
   interfaces to MongoDB's aggregation capability.

/reference/aggregation-commands-comparison
   A comparison of `mapReduce` and `aggregate`
   commands.

/reference/operator/aggregation
   Aggregation pipeline operations have a collection of operators
   available to define and manipulate documents in pipeline stages.

/reference/aggregation-variables
   Use of variables in aggregation pipeline expressions.

/reference/sql-aggregation-comparison
   An overview common aggregation operations in SQL and MongoDB using
   the aggregation pipeline and operators in MongoDB and common SQL
   statements.
