# Authentication Commands

**Note:**

For details on a specific command, including syntax and examples,
click on the link to the command's reference page.

| Name | Description |
|---|---|
| `authenticate` | Starts an authenticated session using a username and password. |
| `getnonce` | This is an internal command to generate a one-time password for authentication. |
| `logout` | *Deprecated*. Terminates the current authenticated session. |
