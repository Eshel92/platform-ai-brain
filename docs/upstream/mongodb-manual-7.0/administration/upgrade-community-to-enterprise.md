# Upgrade MongoDB Community to MongoDB Enterprise

MongoDB Enterprise provides various features not available in the
MongoDB Community edition, such as:

- /core/inmemory

- /core/auditing

- /core/kerberos

- /core/security-ldap and /core/security-ldap-external

- /core/security-encryption-at-rest

The documents in this section provide instructions to upgrade from
MongoDB Community Edition to MongoDB Enterprise Edition.

**Important:**

Do not use these instructions to upgrade to another release version.

For general guidance on MongoDB version numbering, release types, and
upgrade paths, see versions-and-upgrade-paths.

**Note:**

If you use [MongoDB Atlas](https://www.mongodb.com/docs/atlas), the fully
managed service for MongoDB deployments in the cloud, you can 
easily upgrade your MongoDB version. To migrate from
MongoDB Community Edition to MongoDB Atlas, see 
Migrate or Import Data.
