# Release Notes for MongoDB 7.0

For general guidance on MongoDB version numbering, release types, and
upgrade paths, see versions-and-upgrade-paths.

**Important:**

If you run a MongoDB version earlier than 7.0.17 with TLS enabled using the 
`openssl-3.2.2-6.el9_5.x86_64` package, `mongod` might show high CPU usage even 
under a light workload due to a openssl version bug. To resolve this issue, upgrade to MongoDB 
7.0.17 or later, or use one of the following workarounds:

- Downgrade the openssl package to a version earlier than `openssl-3.2.2-6.el9_5.x86_64`.
- Disable TLS for the MongoDB deployment (not recommended).

MongoDB 7.0 is a Major Release, which means that it is supported for
both MongoDB Atlas and on-premises deployments. MongoDB 7.0 includes
changes introduced in MongoDB Rapid Releases 6.1, 6.2, and 6.3. This
page describes changes introduced in those Rapid Releases and MongoDB
7.0.

To learn more about the differences between Major and Rapid releases,
see release-version-numbers.
