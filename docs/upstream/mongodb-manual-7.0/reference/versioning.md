# MongoDB Versioning

MongoDB Server, MongoDB Atlas, the MongoDB drivers, and MongoDB tools use
separate version numbers. Use the following sections to find version
guidance for each product.

## Server Versions

To learn how MongoDB Server versions are numbered, which release types
are available, and how to plan an upgrade, see
versions-and-upgrade-paths. For per-version release notes and
compatibility changes, see server-release-notes-landing.

## Atlas Versions

To learn about the release options available for Atlas clusters, see
atlas-versions.

## Driver Versions

The version numbering system for MongoDB differs from the system
used for the `MongoDB drivers`.

## MongoDB Shell (`mongosh`)

The `MongoDB Shell` (`mongosh`) is released separately 
from the MongoDB Server and uses its own version numbering system.

## Database Tools

`MongoDB Database Tools` are released separately
from the MongoDB Server and use their own version numbering system.
