# CRUD Commands

CRUD commands *create*, *read*, *update*, and *delete* documents.

| Name | Description |
|---|---|
| `aggregate` | Runs an aggregation pipeline on a collection or view. |
| `count` | Counts documents in a collection or view. |
| `delete` | Deletes one or more documents. |
| `distinct` | Returns distinct values in a specified field from a collection or view. |
| `find` | Selects documents in a collection or view. |
| `findAndModify` | Returns and modifies a single document. |
| `insert` | Inserts one or more documents. |
| `mapReduce` | Performs map-reduce aggregation. |
| `update` | Updates one or more documents. |
