# Third-Party Integrations

Kubernetes Operator offers the following third-party integrations.

| Third-Party Service | Configuration Details |
|---|---|
| Grafana | Kubernetes Operator offers a sample Grafana dashboard that you can [import into Grafana](https://grafana.com/docs/grafana/latest/dashboards/export-import/#import-dashboard). |
| Prometheus | You can use Kubernetes Operator to deploy a MongoDB resource or application database to use with Prometheus. |
