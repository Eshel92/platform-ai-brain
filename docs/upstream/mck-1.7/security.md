# Security

The MongoDB Controllers for Kubernetes Operator provides various security features
to secure your MongoDB deployments.

k8s-permissions
  Verify the permissions for your Kubernetes Operator 
  objects.

k8s-signatures
  Verify the signature file before running the MongoDB binary.

k8s-gatekeeper
  Control, audit, and debug your deployments by using policies
  for the Gatekeeper Open Policy Agent (OPA).

k8s-encryption
  Configure HTTPS (Hypertext Transfer Protocol Secure) and TLS (Transport Layer Security) to encrypt your data over
  the network.

k8s-encryption-at-rest
  Configure encryption at rest by using a KMIP (Key Management Interoperability Protocol) server. 

k8s-authentication
  Set up X.509, LDAP, OIDC, or SCRAM user authentication.

k8s-secret-storage
  Use the secret storage tool to store sensitive information.
