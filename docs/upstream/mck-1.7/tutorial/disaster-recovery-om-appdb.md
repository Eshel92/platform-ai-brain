# Disaster Recovery for Ops Manager and AppDB Resources

recover-om-yes-k8sop-cluster
  Recover the Ops Manager Application if the central cluster is operational.

recover-om-no-k8sop-cluster
  Recover the Kubernetes Operator and Ops Manager Application if the central cluster
  fails.

recover-appdb-forced-reconfig
  Recover the Application Database\'s replica set when the replica
  set no longer has a majority of nodes to elect a primary.
