# Manage Database Users

k8s-manage-db-users-ldap
  Manage database users using LDAP (Lightweight Directory Access Protocol) authentication on MongoDB
  deployments.

k8s-manage-db-users-scram
  Manage database users using SCRAM authentication on MongoDB
  deployments.

k8s-manage-db-users-x509
   Manage database users for deployments running with TLS and X.509
   internal cluster authentication enabled.

k8s-manage-db-users-oidc
  Manage database users using OpenID Connect authentication on MongoDB
  deployments.
