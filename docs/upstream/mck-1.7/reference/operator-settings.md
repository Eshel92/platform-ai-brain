# MongoDB Controllers for Kubernetes Operator Installation Settings

When you install the Kubernetes Operator, you can provide optional settings
that affect your deployment.  How you provide these settings depends on
the environment to which you deploy the Kubernetes Operator.

meko-op-install-settings-kubectl-oc
  Review the settings that you can use when you install the
  Kubernetes Operator using [kubectl](https://kubernetes.io/docs/reference/kubectl/kubectl/) or [oc](https://docs.openshift.com/container-platform/4.12/cli_reference/index.html).

meko-op-install-settings-helm
  Review the settings that you can use when you install the
  Kubernetes Operator using Helm.
