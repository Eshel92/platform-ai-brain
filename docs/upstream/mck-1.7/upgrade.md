# Upgrade the Kubernetes Operator from Prior Versions

upgrade-k8s-operator
  Upgrade the Kubernetes Operator to its latest version.

migrate-k8s-images
  Migrate your Kubernetes Operator deployments from Ubuntu-based container
  images to UBI-based container images.

**Note:**

To upgrade the versions of your Ops Manager instance and backing databases
that the Kubernetes Operator uses to manage your deployment, see meko-upgrade-om-version.
To upgrade the versions of your MongoDB resource, see meko-upgrade-mdb-version.
